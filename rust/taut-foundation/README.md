# taut-foundation

The `no_std + alloc` Rust owner of Taut's deterministic CBOR codec, immutable
descriptors and optional explicit validation. This crate contains no compiler
or delivery-shape engine. The `validation` feature enables the shared reports
and traversal engine; descriptors and codecs are always present.

Use `taut-foundation = "0.11"` for package runtime bindings generated by
`taut-proto` 0.11. Generated schemas and `taut-shape` must resolve the same crate
owner so codec, descriptor and validation types retain nominal identity.
Applications select dependencies themselves; generation never installs them.

The source files are derived byte for byte from Taut's canonical runtime with
`python rust/sync_foundation.py`; `provenance.json` records their source paths
and SHA-256 hashes. Run `python rust/sync_foundation.py --check` in Taut to
verify them. The registry package contains the entire runtime closure and
builds without a sibling Taut checkout, Python, or a local Cargo patch.

This initial registry release belongs to the 0.11 minor train. The new typed
owner and generated API are not a promise of source or binary compatibility
with earlier locally patched runtimes.
